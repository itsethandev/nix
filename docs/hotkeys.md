# Hotkeys

## How hotkeys are laid out

The modifier keys group hotkeys by purpose, so you can use the combination to anticipate what a hotkey does.

| Key combination | Purpose |
| --- | --- |
| `Super + key` | Window and workspace controls, layouts, and core menus |
| `Super + Shift + key` | Launching apps |
| `Super + Ctrl + key` | Panels and system menus |
| `Super + Ctrl + Alt + key` | Quick actions and notices |

Adding `Alt` changes how the same action works; it never assigns an unrelated action to that hotkey.

## Navigating

| Hotkey | Action |
| --- | --- |
| `Super + Space` | Open the app launcher |
| `Super + Escape` | Open the system menu |
| `Super + W` | Close the window |
| `Super + T` | Toggle the window between tiling and floating |
| `Super + O` | Toggle whether the window is pinned |
| `Super + L` | Cycle through the dwindle, scrolling, and master layouts |
| `Super + Alt + L` | Cycle through the layouts in reverse |
| `Super + F` | Make the window full screen |
| `Super + 1/2/3/4/…` | Switch to the numbered workspace |
| `Super + Shift + 1/2/3/4/…` | Move the window to the numbered workspace and follow it |
| `Super + Shift + Alt + 1/2/3/4/…` | Move the window to the numbered workspace without following it |
| `Super + Arrow` | Focus the window in that direction |
| `Super + Shift + Arrow` | Swap the window with another in that direction, including across monitors |
| `Super + Shift + Alt + Arrow` | Move the window to the monitor in that direction |
| `Super + Tab` | Cycle monitor focus |
| `Super + Alt + Tab` | Cycle monitor focus in reverse |
| `Super + Left Click` | Drag the window |
| `Super + Right Click` | Resize the window |
| `Super + Middle Click` | Reset zoom |
| `Super + Scroll` | Zoom |

## System controls

| Hotkey | Action |
| --- | --- |
| `Super + Ctrl + Space` | Toggle the menu |
| `Super + Ctrl + A` | Open the audio panel |
| `Super + Ctrl + B` | Open the Bluetooth panel |
| `Super + Ctrl + M` | Open the display panel |
| `Super + Ctrl + N` | Open the network panel |
| `Super + Ctrl + P` | Open the power panel |
