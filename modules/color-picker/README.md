# Color picker

`modules.homeManager.color-picker` adds a launcher that picks a screen color and copies its lowercase hex value (`#rrggbb`) to the clipboard. With Hyprland, Super+Ctrl+C picks hex and Super+Ctrl+Alt+C picks RGB (`rgb(r, g, b)`). Cancelling leaves the clipboard unchanged. Requires a Linux Wayland compositor supported by Hyprpicker.
