# macOS window management

`modules.darwin.window-management` enables AeroSpace with automatic tiling and eight-pixel gaps.

Bindings approximate the [system hotkeys](../../docs/hotkeys.md), using Cmd for Super. Cmd+H/J/K/L changes focus; adding Shift moves windows. Cmd+1–9 selects workspaces; adding Shift+Alt moves windows to them without following. Cmd+Tab cycles monitor focus. Cmd+F toggles fullscreen and Cmd+T toggles floating layout. macOS-hidden applications are automatically unhidden.
