# Screenshots

`modules.homeManager.screenshots` installs Omasnap on Linux. With Hyprland enabled and using Lua configuration, it adds the screenshot bindings listed in [system hotkeys](../../docs/hotkeys.md).

The smart picker freezes the focused monitor: drag for a region, click a window, or click empty background for the monitor. Press `E` or `A` before selecting to annotate with drawing, arrows, text, shapes, highlighting, and redaction. Window capture crops the visible screen, including overlapping windows.

Captures copy to the clipboard and save under `~/Pictures/Screenshots`. Both shortcuts show a preview with an Edit action. Omasnap works without Omarchy and uses its default colors when no Omarchy theme exists. Noctalia is not required.
