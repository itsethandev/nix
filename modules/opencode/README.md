# OpenCode

`modules.homeManager.opencode` installs the OpenCode CLI and desktop app on Linux and macOS, with the shared agent instructions, ItsSkills catalog, and `opencode-mobile-notifications` plugin. Web searches and page fetches are allowed without prompts for all agents by default. Shared instructions encourage proactive web research. The question tool is denied by default.

Herdr integration is added when Herdr is enabled. The CLI shows large pastes as full text and uses the Stylix theme when Stylix is enabled.

With Hyprland and Ghostty independently enabled, Super+Shift+A opens OpenCode in a plain Ghostty terminal.
