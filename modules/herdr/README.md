# Herdr

`modules.homeManager.herdr` enables Herdr on Linux and macOS with Fish as its default shell, J/K workspace navigation, terminal colors, and system notifications. Configure it through `programs.herdr`.

On Linux, a graphical-session user service maintains the server and leaves an already-running server alone. It does not require Ghostty. Select a graphical session separately for automatic startup. No startup job is added on macOS.
