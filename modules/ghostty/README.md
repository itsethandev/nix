# Ghostty

- `modules.darwin.ghostty` installs Ghostty through Homebrew and keeps its windows tiled when AeroSpace is enabled. Requires an existing Homebrew installation.
- `modules.homeManager.ghostty` configures Ghostty on Linux with explicit copy/paste and font-size shortcuts. With Hyprland, Super+Shift+Return opens it and windows receive translucent backgrounds. When Herdr is independently enabled, Ghostty launches it. Herdr's server lifecycle is configured separately.
