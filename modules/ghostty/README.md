# Ghostty

- `modules.darwin.ghostty` installs Ghostty through Homebrew and keeps its windows tiled when AeroSpace is enabled. Requires an existing Homebrew installation.
- `modules.homeManager.ghostty` configures Ghostty on Linux with explicit copy/paste and font-size shortcuts. With Hyprland, Super+Return opens it and windows receive translucent backgrounds. With Herdr, Ghostty launches Herdr and a graphical-session service maintains its server.
