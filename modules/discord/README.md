# Discord

`modules.homeManager.discord` installs Discord on Linux and macOS. Requires permission to use unfree packages.

When Hyprland is independently enabled, Super+Shift+D opens Discord, and Super+Ctrl+V holds to mute only Discord through its registered Push to Mute global shortcut. Configure that action in Discord's Keybinds settings and use Voice Activity mode. Discord popouts float above other windows and remain visible across workspaces.
