# Newton

`darwinConfigurations.newton` configures an aarch64 Mac with integrated Home Manager for `ethan` at `/Users/ethan`.

Enables AeroSpace tiling, Ghostty through Homebrew, Fish and Herdr, Git, Neovim, AI development tools, and an Everforest Stylix theme. Applies macOS desktop preferences and enables Touch ID and Apple Watch authentication for sudo.

Installs [shared agent CLI tools](../../modules/agent-tools) into the user environment for Pi and OpenCode.

Requires an existing Homebrew installation.
